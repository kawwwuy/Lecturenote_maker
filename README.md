# 🛡️ 보안전문가 과정 복습 전용 올인원 에이전트 시스템

본 프로젝트는 보안전문가 교육 과정을 수강하며 다루는 방대한 강의 자료, 실습 영상, 소스 코드 및 로그 데이터를 효과적으로 복습하기 위해 구축된 **로컬 AI 기반 에이전트 웹 앱**입니다. 

보안 정책상 외부 유출이 불가능한 교안 데이터를 안전하게 다루기 위해 외부 클라우드 API를 쓰지 않고, **내 컴퓨터(로컬 RAM 및 GPU) 자원만을 활용하여 100% 오프라인**으로 작동합니다.

---

## 🚀 4대 핵심 에이전트 기능

### 🎬 1번 기능: 동영상 강의 ➔ 텍스트 노트 변환 에이전트
* **역할**: 강사님의 실시간 시연 영상이나 강의 녹화본(`.mp4`)을 업로드하면 오디오를 추출하고 받아 적은 뒤(STT), 보안 핵심 개념 위주의 요약 노트를 자동으로 생성합니다.
* **특화 포인트**: 암호학 알고리즘, 포렌식 절차, 모의해킹 기법 등 말로 설명한 핵심 기술 키워드를 정확하게 파싱합니다.

### 📚 2번 기능: 다중 이기종 문서 ➔ 단일 마스터 노트 융합 에이전트
* **역할**: PDF(교재), Word/HWP(실습 가이드), Excel(취약점 체크리스트), MD(개인 필기) 등 다양한 포맷의 파일을 업로드하면 중복된 내용을 지능적으로 제거하고 하나의 매끄러운 단일 강의 노트로 통합 컴파일합니다.

### 💻 3번 기능: 실습 코드 및 실습 가이드 분석 에이전트
* **역할**: 강사가 제공하는 Python, 머신러닝·딥러닝 실습 코드와 네트워크·보안 실습 가이드 등을 업로드하면 코드와 실습 절차를 분석하여 학습자가 내용을 이해하고 직접 따라 할 수 있도록 단계별 설명과 실습 환경, 실행 방법, 오류 해결 방법 등을 제공합니다.

### 🔍 4번 기능: 교안 기반 지식 검색 시스템 (RAG 챗봇)
* **역할**: 업로드해 둔 모든 교안 데이터를 메모리에 색인(Index)해 두었다가, 사용자가 질문을 던지면 외부 DB 설치 없이 가상 메모리 공간에서 관련 교안 내용을 초고속 서치하여 정확한 출처와 함께 답변을 제공합니다.

## 📂 프로젝트 폴더 구조 (Directory Tree)

```text
security-agent/
├── app.py                  # 🎨 Streamlit 메인 실행 파일 (화면 및 메뉴 전환)
├── requirements.txt        # 📦 필요한 라이브러리 목록 기록 파일
│
├── agents/                 # 🤖 기능별 에이전트 소스코드 폴더
│   ├── __init__.py         
│   ├── video_agent.py      # 🎬 1번 기능: 동영상 ➔ STT 강의노트
│   ├── document_agent.py   # 📚 2번 기능: 다중 문서(PDF/Word 등) 통합
│   ├── code_agent.py       # 💻 3번 기능: 강사 실습자료 분석 → 실습 방법 안내 및 실행 지원
│   └── search_agent.py     # 🔍 4번 기능: 교안 기반 지식 서치 챗봇 (메모리 가동)
│
└── utils/                  # 🛠️ 파일 텍스트 추출 도구 폴더
    ├── __init__.py
    └── file_parser.py      # PDF, DOCX 등 파일에서 글자 긁어모으는 도구
```

## 🛠️ 기술 스택 (Tech Stack)
* **UI Framework**: Streamlit
* **LLM Engine**: Ollama (Model: `benedict/linkbricks-llama3.1-korean:8b`)
* **STT Engine**: OpenAI Whisper (`openai-whisper`)
* **Video/Audio Parser**: MoviePy
* **Document Parsers**: PyPDF, python-docx, openpyxl
* **Vector Search**: Meta FAISS (`faiss-cpu`)
