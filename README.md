# 🛡️ 보안전문가 과정 복습 전용 올인원 에이전트 시스템

보안전문가 과정에서 학습한 **강의 영상, 강사 교안, 실습 자료, 실습 코드 및 기타 학습 자료를 통합하여 복습을 지원하는 AI 기반 웹 애플리케이션**입니다.

강의별 자료를 하나의 강의노트로 정리하고, 여러 강의에서 생성된 강의노트와 추가 학습자료를 하나의 **Master Note**로 통합합니다.

또한 강사가 제공한 Python, 머신러닝/딥러닝 실습 코드와 네트워크·보안 실습자료를 분석하여 학습자가 코드를 이해하고 직접 실습할 수 있도록 지원하며, 축적된 과정 자료를 기반으로 RAG 챗봇을 통해 질문하고 답변을 받을 수 있도록 구성합니다.

---

## 🎯 프로젝트 목표

보안전문가 과정에서 학습한 자료가 강의별로 흩어지는 문제를 해결하고,

> **강의 → 강의노트 → Master Note → RAG 복습**

으로 이어지는 하나의 학습 흐름을 구축하는 것을 목표로 합니다.

### 전체 학습 흐름

```text
┌──────────────────────┐
│     강의 영상        │
└──────────┬───────────┘
           │
           │ STT
           ▼
┌──────────────────────┐
│     강사 교안        │
└──────────┬───────────┘
           │
           │
           ▼
┌────────────────────────────┐
│  1. 강의노트 생성 에이전트  │
│  영상 내용 + 교안 통합      │
└────────────┬───────────────┘
             │
             ▼
        [강의노트]
             │
             │ 여러 강의
             ▼
┌────────────────────────────┐
│  2. Master Note 통합 에이전트│
│  강의노트 + 추가 학습자료   │
└────────────┬───────────────┘
             │
             ▼
        [Master Note]
             │
             ▼
┌────────────────────────────┐
│  4. RAG 복습 챗봇           │
│  과정 자료 기반 질의응답    │
└────────────────────────────┘


┌────────────────────────────┐
│ 3. 실습 코드/자료 지원 에이전트│
│ Python / ML / DL / 네트워크 │
│ 보안 실습 / Packet Tracer   │
└────────────────────────────┘
```

# 🤖 4대 핵심 에이전트

## 1️⃣ 동영상 + 교안 기반 강의노트 생성 에이전트

### 목적

하나의 강의에 포함된 **강의 영상과 해당 강의의 강사 교안**을 함께 분석하여 하나의 통합 강의노트를 생성합니다.

단순히 영상을 텍스트로 변환하는 것이 아니라, 영상에서 강사가 추가로 설명한 내용과 교안의 내용을 결합하는 것을 목표로 합니다.

### 입력

* 강의 영상

  * `.mp4` 등
* 해당 강의의 강사 교안

  * `.pdf`
  * `.docx`
  * `.hwp` 등 지원 가능한 형식

### 처리 과정

```text
강의 영상
   ↓
오디오 추출
   ↓
STT
   ↓
강의 내용 텍스트

강사 교안
   ↓
텍스트 추출
   ↓
교안 내용

        ↓
   내용 분석/통합
        ↓
    강의노트 생성
```

### 예시

강사 교안에 다음 내용이 있다고 가정합니다.

```text
SQL Injection
- 정의
- 발생 원인
- 방어 방법
```

강의 영상에서는 추가로 다음 내용을 설명할 수 있습니다.

```text
Burp Suite를 이용하여
HTTP Request의 파라미터를 변경하는 실습
```

최종 강의노트에는 교안의 이론 내용과 영상에서 추가된 실습 설명을 함께 포함합니다.

### 주요 기술

* OpenAI Whisper
* MoviePy
* PDF/DOCX 텍스트 추출
* LLM 기반 내용 분석 및 통합

### 개발 브랜치

```text
feature/1-video-note
```

# 2️⃣ 다중 강의자료 Master Note 통합 에이전트

## 목적

1번 에이전트에서 생성된 여러 개의 **강의노트**와 과정에서 사용되는 추가 학습자료를 통합하여 하나의 **Master Note**를 생성합니다.

1번이 **하나의 강의 단위**를 처리한다면,

2번은 **전체 과정의 학습자료를 통합**하는 역할을 담당합니다.

### 입력

```text
강의노트 01
강의노트 02
강의노트 03
...
```

추가적으로 다음과 같은 학습자료를 사용할 수 있습니다.

```text
PDF
Word
HWP
Excel
Markdown
기타 텍스트 자료
```

### 처리 과정

```text
강의노트 01 ─┐
강의노트 02 ─┤
강의노트 03 ─┤
교안 자료   ─┤
실습 자료   ─┤
기타 자료   ─┘
       ↓
텍스트 추출
       ↓
내용 정제
       ↓
중복 내용 정리
       ↓
주제별 통합
       ↓
    Master Note
```
